Instruções de interação do jogo - Primeira entrega:

-> Na tela inicial, aperte com o botão esquerdo do mouse sobre o botão Iniciar para avançar;

-> No próximo ambiente, movimente o personagem (aparência temporária) pelo escritório (layout temporário) utilizando as setinhas presentes no teclado. Para avançar, vá até o computador presente no meio, e aperte a tecla espaço enquanto encostar em sua área de colisão;

-> Na tela de login, aperte com o botão esquerdo do mouse sobre o ícone para avançar;

-> Na tela da área de trabalho, aguarde o email terminar a sua movimentação. Quando o mesmo ficar parado, aperte-o com o botão esquerdo do mouse para prosseguir;

-> Essa tela é a principal representação do conceito do jogo, apresentando uma contextualização básica sobre a história, além do que virá a seguir. Após o início dessa cena, aguarde 3 segundos para poder prosseguir. Após esse período, aperte o botão "Começar tarefa" para prosseguir;

-> Essa tela temporária é a última desenvolvida, representando o início de um minijogo.
